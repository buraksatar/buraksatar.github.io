{% comment %} Collapsible BibTeX block with a copy button. Reads page.bibtex by default; pass `entry` and `uid` to render an arbitrary one, which is what _includes/pub-entry.html does when several papers appear on the same page. The id is derived from the page or the caller's uid. It used to be a hardcoded id="bibtex-entry", which was fine on a single paper page but meant every copy button on /publications/ would have copied the first entry. The copy handler lives in assets/js/site.js as one delegated listener, rather than an inline onclick (which any future CSP would block) with no failure path. {% endcomment %} {% assign bib = include.entry | default: page.bibtex %} {% if bib %} {% assign uid = include.uid | default: page.url | slugify %}
